# Academic Timetable Generator

A full-stack web application that automatically generates conflict-free academic timetables using a genetic algorithm.

## 🚀 Technologies

* Java
* Spring Boot
* React.js
* PostgreSQL
* JWT Authentication
* REST APIs

## ✨ Features

* Automatic timetable generation
* Genetic algorithm-based scheduling
* Conflict-free timetable generation
* JWT-based authentication
* Role-based access control
* RESTful APIs
* PostgreSQL database integration

## 🏗️ Project Overview

The application uses a genetic algorithm to generate optimized academic timetables while minimizing scheduling conflicts. The Spring Boot backend provides secure REST APIs, while React.js is used to build the frontend interface.

## 🔐 Security

* JWT authentication
* Role-based authorization
* Secured REST APIs

## 🗄️ Database

PostgreSQL is used for storing and managing application data.
